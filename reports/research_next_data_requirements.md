# 下一阶段数据需求与优化路线（给导师讨论）

## 当前证据

当前研究在河北四站公开数据上完成了时间划分、物理基线、本地 9B 模型微调、冻结方案的最终测试和训练期滚动 XGBoost 探索。主测试 232 条上，条件物理 / 未微调 9B / 最终微调 9B 的 MAE 分别为 **0.8622 / 0.7960 / 0.8437 h**。大模型基座在此测试期有帮助，但本次微调没有超过基座；简单加长训练或在同一测试期调修正幅度没有可靠依据。详细统计见[最终测试报告](research_final_test_results.md)。

## 优先取得的数据

| 优先级 | 字段与粒度 | 为什么需要 |
| --- | --- | --- |
| 必需 | 场站 ID、所在时区、纬经度、每 15 分钟或每小时**实测交流功率**（MW）与停机/限电/缺测标记 | 形成可核验的日发电量标签，区分模型误差与设备停机。 |
| 必需 | 对应历史天气预报的**发布时间**、预报有效时间、预报提前量，以及 GHI、DNI、气温、风速等 | 严格证明每条预测用的是当时已发布的天气；避免把事后天气当预报。 |
| 必需 | 场站直流/交流额定容量及容量变更日期 | 正确计算满负荷小时和物理功率上限。 |
| 高 | 组件倾角、方位角、固定/跟踪方式、组件温度系数、逆变器参数、遮挡/积灰信息 | 把 GHI 转为阵列平面辐照度，替换现版统一的 NOCT、温度系数和逆变效率假设。 |
| 高 | 实测辐照度、气温、组件温度及设备运行状态 | 用于**事后诊断**天气预报误差与物理模型误差；若预测时不可获得，不可输入模型。 |

尽量覆盖 **至少一个完整四季，优先两年及以上**，并保留一个时间上更晚、从未用于调参的评估期。若能得到上海场站，应把上海作为单独的外部验证对象；不能把河北结果直接描述为上海预测精度。共享前需明确数据使用范围和脱敏要求。

## 预测任务边界

- **日前日发电量**：在前一天固定时点，使用当时已发布的目标日天气预报，预测次日总 MWh；这是目前论文和模型的实际任务。
- **月内发电量汇总**：每天产生日前预测，再把当月逐日预测相加，可以得到运行中的月累计或月度估计，但不是月初一次性预测整月。
- **真正的月前预测**：月初一次性预测未来整月总 MWh，需要对应提前量的季节/中长期天气预报或气候情景，须另设模型、输入和评估。不能用每天滚动取得的次日天气预报回填月初任务。

## 新数据到手后的实验顺序

1. 锁定日前预测发布时间、目标和时间切分，保留最终独立期；先做数据质量、缺测、限电和容量变更审计。
2. 在训练期内部做滚动时间验证，先重建更完整的组件面辐照度、温度和逆变器物理预测；同时训练同字段的线性/树模型与未微调 9B 对照。
3. 在这些基线上训练大模型残差修正。重点测试能表示**跨季节偏差**的目标和输出形式，例如更细分档或数值回归；但要用训练期滚动折决定，不能追逐旧测试期的偏差。
4. 固定模型、提示词、校正规则与评价方案后，才一次性评分新的独立期。报告合并、逐站、逐季节 MAE/RMSE/偏差和日期块区间；若大模型没有稳定增益，也按实写入论文。

当前[课程论文初稿](research_paper_draft.md)已经可以用于课程讨论；若导师希望强调“微调模型优于基座”，现有证据不足，需要新数据和新的独立评估，不能通过改写现有结果实现。
