# 步骤 12 结果：只监督类别 token 的 9B 微调

## 预先固定的问题与实现核查

本轮只改变步骤 9 的损失目标：训练时每条样本仅监督真实的 A/B/C 类别 token，模型、890 条训练样本、提示、LoRA 配置、学习率、890 次更新、类别边界和数值恢复方式均沿用[运行前方案](research_class_only_v4_protocol.md)。自定义损失严格使用 `offset <= step < sequence length`；对全部 890 条训练和 184 条验证样本完成检查，每条恰好一个受监督 token，最长 384 token。原 `mlx-lm` 默认长度右端包含补齐位置，首次单步试运行因此被归档为失败；修订后单步试运行成功，才运行完整训练。旧版评估器的默认 v3 输出与哈希未因新增 v4 选项而改变。

完整训练 890/890 次更新、无 Metal 内存错误，使用第 890 步权重评分，没有事后选择中间检查点。最后一次训练器抽样验证类别损失为 1.086；下表“类别交叉熵”则是在全部验证/旧测试样本上，对 A/B/C **受限归一化概率**重新计算的另一指标。两者样本和归一化空间不同，不能直接相减。

## 预测误差

单位为等效满负荷小时。旧测试的 232 条主口径排除已意外暴露的一整日；本轮已在原最终测试之后开展，所有旧测试数字均为**回顾性诊断，不是新独立测试**。

| 方法 | 验证 MAE / RMSE | 旧测试 232 条 MAE / RMSE | 旧测试 236 条 MAE / RMSE |
| --- | ---: | ---: | ---: |
| 条件物理 | 0.6834 / 0.8534 | 0.8622 / 1.1376 | 0.8737 / 1.1706 |
| 未微调 9B 基座 | 0.7035 / 0.8712 | **0.7960 / 1.0441** | **0.8071 / 1.0776** |
| 原完整回复损失 v3 adapter | **0.6757 / 0.8444** | 0.8437 / 1.1110 | 0.8558 / 1.1454 |
| 仅类别 token 损失 v4 adapter | 0.6774 / 0.8465 | 0.8422 / 1.1094 | 0.8543 / 1.1440 |

按日期块 bootstrap 10,000 次，v4 对 v3 的 MAE 改善在验证期为 −0.0016 h，95% 描述性区间 [−0.0048,+0.0015] h；旧测试 232 条为 +0.0015 h，区间 [−0.0011,+0.0041] h。两期都不足以确认 v4 优于 v3。v4 对条件物理的旧测试改善为 +0.0200 h，区间 [+0.0112,+0.0293] h，但它比未微调基座**差** 0.0462 h，区间 [−0.0750,−0.0162] h。后两项也只是对既有测试期的回顾统计，不可视为本轮独立确认。

## 类别和误差诊断

| 模型 | 验证类别交叉熵 / 准确率 | 旧测试 232 条类别交叉熵 / 准确率 | 旧测试平均修正 / 修正标准差（h） |
| --- | ---: | ---: | ---: |
| 未微调 9B | 1.1685 / 29.9% | **1.0375 / 45.7%** | −0.2340 / 0.0762 |
| v3 adapter | **1.0856 / 37.5%** | 1.0794 / 40.5% | −0.0273 / 0.0648 |
| v4 adapter | 1.0935 / 37.0% | 1.0767 / 43.5% | −0.0293 / 0.0658 |

三类均匀概率的交叉熵为 $\ln 3\approx1.0986$。仅监督类别并未提高完整验证集的类别交叉熵；v4 的验证修正与真实残差相关系数为 0.1399，低于 v3 的 0.1777。旧测试期真实条件物理残差的标准差为 1.0439 h，v4 的修正标准差仅 0.0658 h，说明模型仍主要给出近乎常数的修正，而非辨认逐日误差。

旧测试逐站 v4 MAE 为 S-1 0.502、S-2 1.414、S-3 0.679、S-4 0.773 h；S-2 的条件物理 MAE 1.476 h、平均高估 1.198 h，仍是最大误差来源。未微调基座在旧测试期平均修正约 −0.234 h，因而在该段偏差较大的时间恰好更合适；不能据此在旧测试上重新调 v4 的修正强度。验证期则是 v3 略好。**损失目标修复是实现上的改进，但没有带来可靠的预测精度改进。**
