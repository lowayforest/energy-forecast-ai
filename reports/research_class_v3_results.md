# 步骤 9 结果：9B 分档残差模型在验证集上小幅优于条件物理预测

所有预测都只使用训练/验证范围的数据；**测试集没有读取或评分**。重新运行 `.venv/bin/python scripts/compare_research_class_v3.py` 后，比较文件哈希保持不变。最终 adapter、配置和 SFT manifest 的哈希与训练 provenance 完全一致。

## 日期块区间与模型行为

“MAE 改善”定义为参照方法的绝对误差减候选方法的绝对误差。按照运行前方案，同日四站组成一个日期块，对 46 个日期块 bootstrap 重采样 10,000 次（种子 42）：

| 候选相对参照 | 平均改善（h） | 95% 日期块区间（h） |
| --- | ---: | ---: |
| 新 adapter vs 条件物理 | **+0.007695** | **[−0.005798, +0.020153]** |
| 新 adapter vs 新基座 | +0.027768 | [−0.007347, +0.063099] |
| 新 adapter vs 步骤 8 旧 adapter | +0.032572 | [+0.009896, +0.055666] |
| 新 adapter vs 原物理 | +0.104459 | [+0.053820, +0.153006] |

新 adapter 相比条件物理有 **100/184 条站点日**、**32/46 个日期块**的平均绝对误差更低；但主要比较的区间跨零。相比未微调基座的区间也跨零。相比旧 adapter 的区间为正，但本轮同时改变输出表示与训练步数，不能单独归因于分档或某个训练设置。相比原物理的明显改善还包含步骤 8 的条件物理校正贡献，不能全部归功于大模型。

事后诊断：验证集真实的条件物理剩余残差均值为 **−0.0340 h**、标准差 **0.8527 h**；新 adapter 修正的均值为 **−0.0343 h**、标准差 **0.0576 h**，逐条 Pearson 相关约 **0.1777**。按最大类别概率硬判的三档正确率 **37.5%**，而验证集中最多的 C 档占 **71/184≈38.6%**。本方法使用三档概率加权值，而非硬类别，因此硬判正确率并非主评分；这些数字仍说明逐日残差辨别能力有限。训练残差的全局均值约为零、全局中位数 −0.0215 h，分别作为固定修正时，验证 MAE 约为 **0.6834 h** 和 **0.6847 h**。以上为结果出来后的诊断，不是新增的预先指定假设检验。

## 结论、限制与下一步

可以把本轮称为**验证集上的探索性小幅改善**；不能写成“已证明大模型稳定超过条件物理模型”。关键原因是主要日期块区间跨零，且步骤 7—9 连续依据同一验证期分析和设计，区间没有涵盖这种多轮选择带来的不确定性。四站数据来自河北，不能直接代表上海场站；天气输入的逐条预报发布时间无法完全核验，详见[数据审计](research_daily_dataset.md)。目前尚未做独立测试，不应把验证误差当最终泛化结果。

建议先保留这个最终 890 步 adapter 和方案作为**候选模型**，不要继续按当前验证集挑中间权重或改阈值。论文中分别报告条件物理基线、旧数值残差 9B、未微调基座和本轮分档 9B，准确写出小幅改善及其不确定性。若确定论文最终模型与所有处理规则，再一次性打开封存测试集评分，并核对要求的 10—15 篇参考文献。
